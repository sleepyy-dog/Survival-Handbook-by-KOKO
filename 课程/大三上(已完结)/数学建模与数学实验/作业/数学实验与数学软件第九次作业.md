### 作业：P220 第3题（2）

> #### 1.
>
> 3. 对问题
>
> $$
> \min \{100(x_2 - x_1^2)^2 + (1-x_1)^2 + 90(x_4 - x_3^2)^2 + (1-x_3)^2 + 10.1[(1-x_2)^2 + (1-x_4)^2] + 19.8(x_2-1)(x_4-1)\}
> $$
>
> 增加以下条件，并分别取初值$(-3,-1,-3,-1)$和$(3,1,3,1)$，求解非线性规划：
> $$(2) -10 \le x_i \le 10, x_1x_2-x_1-x_2+1.5 \le 0, x_1x_2+10 \ge 0, -100 \le x_1x_2x_3x_4 \le 100;$$
> 再试取不同的初值或用分析梯度计算，比较计算结果。你能从中得到什么启示？

**解：**

这是一个非线性规划问题，我们首先将问题转化为

$$
\begin{array}{ll}
\min & z = f(\boldsymbol{x}) \\[3pt]
\text{s. t.} & \boldsymbol{c}_1(\boldsymbol{x}) \leq \mathbf{0}, \\[3pt]
& \boldsymbol{c}_2(\boldsymbol{x}) = \mathbf{0}, \\[3pt]
& \boldsymbol{A}_1 \boldsymbol{x} \leq \boldsymbol{b}_1, \\[3pt]
& \boldsymbol{A}_2 \boldsymbol{x} = \boldsymbol{b}_2, \\[3pt]
& \boldsymbol{v}_1 \leq \boldsymbol{x} \leq \boldsymbol{v}_2.
\end{array}
\label{30}
$$

此时其中

$$
f(\mathbf{x})=100(x_2 - x_1^2)^2 + (1-x_1)^2 + 90(x_4 - x_3^2)^2 + (1-x_3)^2 + 10.1[(1-x_2)^2 + (1-x_4)^2] + 19.8(x_2-1)(x_4-1)
$$

由题意约束：
\[
-10 \le x_i \le 10,\; i=1,2,3,4,
\]
\[
x_1x_2-x_1-x_2+1.5 \le 0,\quad x_1x_2+10 \ge 0,\quad -100 \le x_1x_2x_3x_4 \le 100.
\]

将不等式统一写成 $c_1(\boldsymbol{x})\le0$ 形式，可取

$$
\boldsymbol{c}_1(\boldsymbol{x})=
\begin{pmatrix}
x_1x_2 - x_1 - x_2 + 1.5\\[3pt]
-\,x_1x_2 - 10\\[3pt]
x_1x_2x_3x_4 - 100\\[3pt]
-\,x_1x_2x_3x_4 - 100
\end{pmatrix}
\le \mathbf{0}.
$$

本题无等式约束，因此

$$
\boldsymbol{c}_2(\boldsymbol{x}) = \mathbf{0},\quad \text{即无等式约束。}
$$

本题无显式的线性不等式与等式约束，故可取

$$
\boldsymbol{A}_1 = \varnothing,\quad \boldsymbol{b}_1 = \varnothing,\quad
\boldsymbol{A}_2 = \varnothing,\quad \boldsymbol{b}_2 = \varnothing.
$$

变量上下界为

$$
\boldsymbol{v}_1 =
\begin{pmatrix}
-10\\-10\\-10\\-10
\end{pmatrix},
\qquad
\boldsymbol{v}_2 =
\begin{pmatrix}
10\\10\\10\\10
\end{pmatrix}.
$$

我们取不同初值

$$
x_{01}=
\begin{pmatrix}
-3\\-1\\-3\\-1
\end{pmatrix},\quad
x_{02}=
\begin{pmatrix}
3\\1\\3\\1
\end{pmatrix},\quad
x_{03}=
\begin{pmatrix}
0\\0\\0\\0
\end{pmatrix} % 这个是我们自己定义的初值
$$

我们首先使用数值梯度计算，得到结果。

同时使用命令`'GradObj', 'on','GradCon', 'on','DerivativeCheck', 'on'`实现分析梯度计算，目标函数和约束函数的梯度设定如下（每个相应1种数值梯度，总共是全为数值梯度和全为分析梯度$2$种情况，同时我们还有三种初值，所以最后会有6种情况）。

代码如下：

```matlab
%% P1

clc;

% 设定参数

initial_points = [-3 -1 -3 -1; 3 1 3 1; 0 0 0 0];
initial_labels = ["(-3,-1,-3,-1)"; "(3,1,3,1)"; "(0,0,0,0)"];
lb = -10*ones(4,1);
ub = 10*ones(4,1);
modes = ["数值"; "解析"];
options_numeric = optimoptions('fmincon','Algorithm','interior-point','Display','off','SpecifyObjectiveGradient',false,'SpecifyConstraintGradient',false);
options_analytic = optimoptions('fmincon','Algorithm','interior-point','Display','off','SpecifyObjectiveGradient',true,'SpecifyConstraintGradient',true,'checkGradients',true);
numInitials = size(initial_points,1);
numModes = numel(modes);
records = repmat(struct('init',"",'mode',"",'sol',zeros(4,1),'fval',0,'iterations',0,'funcCount',0),numInitials*numModes,1);
idx = 1;

% 输出结果

for i = 1:numInitials
    x0 = initial_points(i,:)';
    for j = 1:numModes
        if j == 1
            options = options_numeric;
        else
            options = options_analytic;
        end
        [xopt,fval,exitflag,output] = fmincon(@rosenbrock_like,x0,[],[],[],[],lb,ub,@nonlinear_constraints,options);
        records(idx).init = initial_labels(i);
        records(idx).mode = modes(j);
        records(idx).sol = xopt;
        records(idx).fval = fval;
        records(idx).iterations = output.iterations;
        records(idx).funcCount = output.funcCount;
        idx = idx + 1;
    end
end
fprintf('| %-10s | %-6s | %-40s | %-14s | %-10s | %-18s |\n','初值','梯度','最优解','最优值','迭代次数','目标函数调用次数');
fprintf('|%s|\n',repmat('-',1,114));
for k = 1:numel(records)
    sol_str = sprintf('[% .6f % .6f % .6f % .6f]',records(k).sol);
    fprintf('| %-10s | %-6s | %-40s | %14.6f | %10d | %18d |\n',records(k).init,records(k).mode,sol_str,records(k).fval,records(k).iterations,records(k).funcCount);
end

%% 设置数值梯度和分析梯度

function [f,g] = rosenbrock_like(x)
x = x(:);
x1 = x(1);
x2 = x(2);
x3 = x(3);
x4 = x(4);
f = 100*(x2 - x1^2)^2 + (1 - x1)^2 + 90*(x4 - x3^2)^2 + (1 - x3)^2 + 10.1*((1 - x2)^2 + (1 - x4)^2) + 19.8*(x2 - 1)*(x4 - 1);
if nargout > 1
    g = zeros(4,1);
    g(1) = -400*x1*(x2 - x1^2) + 2*(x1 - 1);
    g(2) = 200*(x2 - x1^2) + 20.2*(x2 - 1) + 19.8*(x4 - 1);
    g(3) = -360*x3*(x4 - x3^2) + 2*(x3 - 1);
    g(4) = 180*(x4 - x3^2) + 20.2*(x4 - 1) + 19.8*(x2 - 1);
end
end

function [c,ceq,gradc,gradceq] = nonlinear_constraints(x)
x = x(:);
x1 = x(1); x2 = x(2); x3 = x(3); x4 = x(4);
prod_val = x1*x2*x3*x4;

c = [x1*x2 - x1 - x2 + 1.5;
     -x1*x2 - 10;
     prod_val - 100;
     -prod_val - 100];
ceq = [];

if nargout > 2
    % gradc(i,j) = ∂c_j/∂x_i, j = 1..4
    gradc = zeros(4,4);
    % ∇c1
    gradc(:,1) = [x2 - 1;
                  x1 - 1;
                  0;
                  0];
    % ∇c2
    gradc(:,2) = [-x2;
                  -x1;
                  0;
                  0];
    % ∇c3 (prod_val - 100)
    gradc(:,3) = [x2*x3*x4;
                  x1*x3*x4;
                  x1*x2*x4;
                  x1*x2*x3];
    % ∇c4 (-prod_val - 100)
    gradc(:,4) = [-x2*x3*x4;
                  -x1*x3*x4;
                  -x1*x2*x4;
                  -x1*x2*x3];

    gradceq = [];
end
end


```

输出结果为：

| 初值          | 梯度 | 最优解                                    | 最优值     | 迭代次数 | 目标函数调用次数 |
| ------------- | ---- | ----------------------------------------- | ---------- | -------- | ---------------- |
| (-3,-1,-3,-1) | 数值 | [-1.108238  1.237165  0.880349  0.774259] | 4.489821   | 27       | 152              |
| (-3,-1,-3,-1) | 分析 | [-1.108238  1.237165  0.880349  0.774260] | 4.489821   | 27       | 40               |
| (3,1,3,1)     | 数值 | [-1.108237  1.237165  0.880349  0.774260] | 4.489821   | 51       | 280              |
| (3,1,3,1)     | 分析 | [-1.108238  1.237165  0.880349  0.774260] | 4.489821   | 48       | 71               |
| (0,0,0,0)     | 数值 | [ 1.420040 -0.190363  1.466046  2.151055] | 487.987943 | 29       | 184              |
| (0,0,0,0)     | 分析 | [ 1.420040 -0.190363  1.466045  2.151054] | 487.987943 | 29       | 67               |

**启示：**

从结果看，初值对收敛点影响明显，不同初值可能落入不同局部极小点，因此非线性规划应结合问题结构选取合理初值或多初值搜索。对比同一初值下数值梯度与解析梯度的结果，可见两者最优解和最优值几乎一致，但解析梯度在相同精度下迭代次数略少、目标函数调用次数显著减少，计算效率更高，说明在可能的情况下，给出正确的解析梯度对中大规模非线性优化非常重要。
