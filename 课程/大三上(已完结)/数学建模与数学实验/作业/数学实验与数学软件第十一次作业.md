> 3.某校60名学生的一次考试成绩如下:
> 93 75 83 93 91 85 84 82 77 76 77 95 94 89 91
> 88 86 83 96 81 79 97 78 75 67 69 68 84 83 81
> 75 66 85 70 94 84 83 82 80 78 74 73 76 70 86
> 76 90 89 71 66 86 73 80 94 79 78 77 63 53 55
> 作直方图，计算均值、标准差、极差、偏度、峰度。

**解：**

我们有以下函数：

| 命令              | 名称   | 输入                                                         | 输出                              | 注意事项                         |
| :---------------- | :----- | :----------------------------------------------------------- | :-------------------------------- | :------------------------------- |
| $[n,y]=hist(x,k)$ | 频数表 | $x$:原始数据行向量 $k$:等分区间数（参考最大值和最小值进行划分） | $n$:频数行向量 $y$:区间中点行向量 | $[n,y]=hist(x)$中$k$取默认值$10$ |
| $hist(x,k)$       | 直方图 | $x$:原始数据行向量 $k$:等分区间数                            | 直方图                            | $[n,y]=hist(x)$中$k$取默认值$10$ |
| $mean(x)$         | 均值   | $x$:原始数据行向量                                           | 均值$\bar{x}$                     |                                  |
| $median(x)$       | 中位数 | $x$:原始数据行向量                                           | 中位数                            |                                  |
| $range(x)$        | 极差   | $x$:原始数据行向量                                           | 极差                              |                                  |
| $std(x)$          | 标准差 | $x$:原始数据行向量                                           | 标准差$s$                         | $std(x,1)$:即$(3)$式中的$s_1$    |
| $var(x)$          | 方差   | $x$:原始数据行向量                                           | 方差$s^2$                         | $var(x,1)$:即$s^2$               |
| $skewness(x)$     | 偏度   | $x$:原始数据行向量                                           | 偏度$g_1$                         |                                  |
| $kurtosis(x)$     | 峰度   | $x$:原始数据行向量                                           | 峰度$g_2$                         |                                  |

实现代码：

```matlab
%% p1

clc;

% 定义数据
x = [93 75 83 93 91 85 84 82 77 76 77 95 94 89 91 ...
     88 86 83 96 81 79 97 78 75 67 69 68 84 83 81 ...
     75 66 85 70 94 84 83 82 80 78 74 73 76 70 86 ...
     76 90 89 71 66 86 73 80 94 79 78 77 63 53 55];

% 输出统计量

% 直方图
k=10;
hist(x,k)

% 极差

% 峰度

```

> #### 4(2)
>
> 1. 用蒙特卡罗方法计算以下函数在给定区间上的积分，并改变随机点数目观察对结果的影响。
>
>    $$
>    y=e^{3x} \sin 2x, 0 \leq x \leq 2
>    $$

**解：**

```matlab
%% P2

clc;

% 先定义参数
N=[10,100,1000,10000,100000,1000000,10000000];
f=@(x) exp(3*x)*sin(2*x);

% 使用均值估计法

for i = 1:length(N)
    n = N(i);
    x=unifrnd(0,2,1,n);
    sum=0;
    for j=1:n
     sum=f(x(j))+sum;
    end
    inte=sum/n*2
end 
```
