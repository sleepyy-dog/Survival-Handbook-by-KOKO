对于以下两题，我们的做法是学习**书本P99例题**先将矩阵A转换再计算，这样的好处是逻辑更清晰。其实我们也可以直接建立两个函数，从A出发求解，如下：

```matlab
%% 雅可比迭代
function [x, iter] = jacobi_iteration(A, b, x0, tol, max_iter)
 
    n = length(b);            
    x = x0;                   
    D = diag(A);              
    R = A - diag(D);
    
    iter = 0;
    while iter < max_iter
        iter = iter + 1;
        
        x_new = (b - R * x) ./ D;
        
        if norm(x_new - x, inf) < tol || norm(x_new - x, inf)/norm(x, inf) < tol
            break;
        end
        
        x = x_new;
    end
    
    if iter == max_iter
        disp('达到最大迭代次数，未收敛');
    else
        disp(['迭代次数: ', num2str(iter)]);
    end
end

%% 高斯-赛德尔迭代
function [x, iter] = gauss_seidel_iteration(A, b, x0, tol, max_iter)

    n = length(b);        
    x = x0;               
    iter = 0;             
    L = tril(A);          
    U = A - L;            

    while iter < max_iter
        iter = iter + 1;
        x_old = x;        

        x = L \ (b - U * x_old);

        if norm(x - x_old, inf) < tol || norm(x_old - x, inf)/norm(x, inf) < tol
            break;
        end
    end

    if iter == max_iter
        disp('达到最大迭代次数，未收敛');
    else
        disp(['迭代次数: ', num2str(iter)]);
    end
end

```



> 2. 分别用雅可比迭代法和高斯-赛德尔迭代法计算下列方程组，均取相同的初值$\textbf{x}^{(0)} = (1,1,1)^T$，观察其计算结果，并分析其收敛性。
>
> $$
> (2)
> \begin{cases}
> 5x_1 - x_2 - 3x_3 = -1, \\
> -x_1 + 2x_2 + 4x_3 = 0, \\
> -3x_1 + 4x_2 + 15x_3 = 4;
> \end{cases}

**解：**注意我们可以转化问题为$\textbf{Ax+b=x}$,其中

$$
\textbf{A}=
\begin{bmatrix}
0 & 1/5 & 3/5 \\
1/2 & 0 & -2 \\
1/5 & -4/15 & 0 \\
\end{bmatrix};
\textbf{b}=
\begin{bmatrix}
-1/5 \\
0 \\

\end{bmatrix};
$$

> [!NOTE]
>
> 这里我们的转化是直接将原矩阵写出，然后每行除一个常数，使得对角线上的元素为1 然后就可以提取出一个单位矩阵了。

我们使用雅可比迭代和高斯-赛德尔迭代法。代码如下：

```matlab

clc;
A=[0,1/5,3/5;1/2,0,-2;1/5,-4/15,0];
b=[-1/5;0;4/15];
X_0=[1;1;1];

% 雅可比函数
function X=ykb(X_0,A,b,k)

m=length(b);

T=ones(m,k+1);

T(:,1)=X_0;

for n=2:k+1
    T(:,n)=A*T(:,n-1)+b;
end

X=T(:,k+1);

end


%sider函数
function X=sider(X_0,A,b,k)

m=length(b);

T=ones(m,k+1);

T(:,1)=X_0;

for n=2:k+1
    for i=1:m

    T(i,n)=A(i,1:i-1)*T(1:i-1,n)+A(i,i:m)*T(i:m,n-1)+b(i);
    
    end
end

X=T(:,k+1);

end

X_1=ykb(X_0,A,b,k)

X_2=sider(X_0,A,b,k)
```

* **收敛性验证**：两种方法在迭代足够多次后，都收敛到了方程组的精确解 $\mathbf{x}^* \approx (-0.0984, -1.1639, 0.5574)^T$。

* **收敛速度分析**：
  * 迭代3次后，高斯-赛德尔解 `(-0.1069, -1.2534, 0.5795)` 已经非常接近最终解，而雅可比解 `(0.2106, -1.7857, 0.2645)` 还相差甚远。
  * 迭代10次后，高斯-赛德尔解几乎已经达到了最终解的精度，而雅可比解依然有明显差距。

1. **收敛性**：尽管系数矩阵不满足严格对角占优这一简单的充分条件，但通过计算各自迭代矩阵的谱半径，可以证明了雅可比法和高斯-赛德尔法都是收敛的，因为它们的谱半径均小于1。
2. **收敛速度**：高斯-赛德尔法的迭代矩阵谱半径（$\approx 0.54$）远小于雅可比法的谱半径（$\approx 0.878$），因此其收敛速度显著更快。这背后的直观解释是，高斯-赛德尔法在同一次迭代中，计算每个分量时都利用了**最新的**已计算出的其他分量的值，信息传递更高效，从而加速了收敛进程。

观察知此时新的迭代方程为

$$
\textbf{x = (1/k)Bx + (1/k)c}
$$

k为我们乘的倍数。

我们有代码如下：

```matlab
%% (2)
clc;
b_fixed = ones(n, 1);
x0_fixed = zeros(n, 1);
tol2 = 1e-5;

% 用六个值来乘
k_values = [1, 2, 5, 10, 20, 50];
iter_counts = zeros(length(k_values), 1);

for i = 1:length(k_values)
    k = k_values(i);

    B_new = (1/k) * B;
    c_new = (1/k) * b_fixed/3;

    [~, iter_count] = ykb2(x0_fixed, B_new, c_new, tol2);

    iter_counts(i) = iter_count;
end

fprintf('固定 x0=zeros, b=ones, tol=1e-5\n');
fprintf('----------------------------------\n');
fprintf('%-16s | %-12s\n', '对角线乘数 k', '迭代次数');
fprintf('----------------------------------\n');
for i = 1:length(k_values)
    fprintf('%-20d | %-12d\n', k_values(i), iter_counts(i));
end
fprintf('----------------------------------\n');

```

输出结果为:

```matlab

----------------------------------
对角线乘数 k          | 迭代次数        
----------------------------------
1                    | 16          
2                    | 9           
5                    | 5           
10                   | 4           
20                   | 4           
50                   | 3           
----------------------------------

```

**k对收敛速度的影响**：

* 由于原始矩阵收敛，有 $0 \le \rho(\mathbf{B_J}) < 1$。
* 当 $k$ 增大时，$1/k$ 减小，因此新的谱半径 $\rho(\mathbf{B_{J,k}})$ 会**急剧减小**并趋向于0。
* 如前所述，谱半径是衡量收敛速度的关键指标。一个更小的谱半径意味着每一次迭代都能更大比例地消除误差，从而使得收敛速度**大大加快**。

结论：可以看出当k越大时，相应的矩阵的谱半径也就最小，此时迭代次数明显下降，也就是说逼近速度快，这也和理论符合的很好。
