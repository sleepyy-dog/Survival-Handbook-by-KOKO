> #### 1.
>
> 1. 考虑如下的$Dirichlet$问题:
>
> $$
> \begin{cases}
> -\Delta u + u = f, & 0 < x, y < 1, \\
> u|_{\Gamma} = \varphi,
> \end{cases}
> $$
>
> 其中$\Gamma$为正方形区域的边界。类似于模型问题，我们得到差分方程
>
> $$
> \begin{cases}
> \left(1 + \frac{h^2}{4}\right) u_{ij} - \frac{1}{4} (u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1}) = \frac{h^2}{4} f_{ij}, \\
> \quad i, j = 1, \dots, n-1, \\
> u_{i,0} = \varphi_{i,0}, u_{i,n} = \varphi_{i,n}, \quad i = 0, 1, \dots, n, \\
> u_{0,j} = \varphi_{0,j}, u_{n,j} = \varphi_{n,j}, \quad j = 0, 1, \dots, n.
> \end{cases}
> $$
>
> 按照自然顺序排列得到系数矩阵为
>
> $$
> A = \begin{pmatrix}
> S' & B & & & \\
> B & S' & B & & \\
> & B & S' & \ddots & \\
> & & \ddots & \ddots & B\\
> & & & B & S'
> \end{pmatrix}
> $$
>
> 其中$B = -I/4$, $I$为$n-1$阶单位矩阵，$S'$是对角元均为$1+h^2/4$，次对角元均为$-1/4$的$n-1$阶对称三对角阵。对$f = \sin(xy)$, $\varphi = x^2 + y^2$, $n = 20$, 用共轭梯度法求解差分方程，要求有4位有效数字。

**解：**

> [!NOTE]
>
> 5.2.1算法如下：
>
> ```matlab
> % 算法 5.2.1 (解对称正定方程组:共轭梯度法)
> 
> % 初始化
> x0 = initial_value;
> r0 = b - A * x0;
> k = 0;
> 
> % 迭代循环
> while norm(rk) ~= 0
>     k = k + 1;
>     if k == 1
>         p0 = r0;
>     else
>         % 计算 beta
>         beta_k_minus_2 = (r_k_minus_1' * r_k_minus_1) / (r_k_minus_2' * r_k_minus_2);
>         % 计算 p
>         p_k_minus_1 = r_k_minus_1 + beta_k_minus_2 * p_k_minus_2;
>     end
>     
>     % 计算 alpha
>     alpha_k_minus_1 = (r_k_minus_1' * r_k_minus_1) / (p_k_minus_1' * A * p_k_minus_1);
>     
>     % 更新 x
>     xk = x_k_minus_1 + alpha_k_minus_1 * p_k_minus_1;
>     
>     % 更新 r
>     rk = r_k_minus_1 - alpha_k_minus_1 * A * p_k_minus_1;
> end
> 
> % 最终解
> x = xk;
> 
> % 注意: 该算法每迭代一次仅需使用系数矩阵 A 做一次矩阵-向量运算。
> ```

首先证明$A$对称正定。

注意到**严格对角占优的对称矩阵是正定矩阵**，则知$A$为对称正定。

代码如下：

```matlab
%% P1

clc;

% 给定参数

n = 20;

f_func = @(x,y) sin(x.*y);
varphi_func = @(x,y) x.^2 + y.^2;

tol=1e-4;

% 使用kron语法定义A

m = n - 1;
h = 1 / n;
e = ones(m,1);
S = spdiags([-0.25*e, (1 + (h^2)/4)*e, -0.25*e], [-1,0,1], m, m);
Bblk = -0.25*speye(m);
T = spdiags([e,e], [-1,1], m, m);
A = kron(speye(m), S) + kron(T, Bblk);

b=diri(f_func,varphi_func,n);

x_0=zeros(m*m,1);

% 求解保留四位的解

x=cgm(A,b,tol,x_0);

x'

```

> #### 2.
>
> 2. 用 $Hilbert$ 矩阵测试你所编写的共轭梯度法程序：
>
> $$
> a_{ij} = (i+j-1)^{-1}, b_i = \frac{1}{3}\sum_{j=1}^{n} a_{ij} \quad (1 \le i, j \le n).
> $$

**解：**

这个对称正定的证明比较难，需要用到**Hilbert 矩阵的二次型**。

代码如下：

```matlab
%% P2

clc;

% 参数定义

n=100;

x_0=zeros(n,1);

% 首先定义A

A=1./(repmat((1:n)',1,n)+repmat(1:n,n,1)-1);

% 再定义b

b=(1/3)*sum(A,2);

% 求解x

t=1e-4;
x=cgm(A,b,t,x_0);

x'

```

> [!NOTE]
>
> 由于 Hilbert 矩阵极度病态，其条件数随维数呈指数级增长。
> 在双精度浮点数下，即使采用理论上收敛的共轭梯度法（CGM），
> 也会出现较大的数值误差。这种误差是***数值不稳定性导致的必然现象***，
> 而非算法错误。
> 因此，本程序的结果在数值分析意义上是***正确的近似解***。

所用函数：

```matlab
% Dirichlet问题求解b

function b=diri(f,varphi,n)
h = 1 / n;
m = n - 1;
xi = (1:m) * h;
yj = (1:m) * h;
[X,Y] = meshgrid(xi, yj);
B = (h^2/4) * f(X, Y);
B(:,1) = B(:,1) + 0.25 * varphi(0, yj)';
B(:,m) = B(:,m) + 0.25 * varphi(1, yj)';
B(1,:) = B(1,:) + 0.25 * varphi(xi, 0);
B(m,:) = B(m,:) + 0.25 * varphi(xi, 1);
b = B(:);
end
```

```matlab
% 共轭梯度法函数
% 共轭梯度法 的英文是 Conjugate Gradient Method,我们叫把函数叫做cgm
% 求解Ax=b(A为对称正定矩阵),x_0为初值，tol为有效数字相应的误差，例如4位有效数字即为t=0.0001

function x=cgm(A,b,tol,x_0)
x = x_0;
r = b - A * x;
nb = norm(b);
p = r;
rr = r' * r;
kmax = size(A,1);
k = 0;
while norm(r) > tol * nb && k < kmax
    Ap = A * p;
    alpha = rr / (p' * Ap);
    x = x + alpha * p;
    r = r - alpha * Ap;
    rr_new = r' * r;
    if sqrt(rr_new) <= tol * nb
        break
    end
    beta = rr_new / rr;
    p = r + beta * p;
    rr = rr_new;
    k = k + 1;
end
end
```
