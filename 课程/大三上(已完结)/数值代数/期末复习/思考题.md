# 思考题

思考题1：证明两个下三角方阵乘积仍为下三角矩阵。

令$A$和$B$均为$n$阶下三角方阵，且$C = A * B$。对于$c_{i,j}$且$i < j$，我们有

$$
c_{i,j} = \sum_{k=1}^{n} a_{i,k}b_{k,j} = \sum_{k=1}^{i} a_{i,k}b_{k,j} + \sum_{k=i+1}^{n} a_{i,k}b_{k,j}
$$

对于$k \le i < j$，有$b_{k,j} = 0$；对于$i < i + i \le k$，有$a_{i,k} = 0$。因此当$i < j$时，$c_{i,j} = 0$。这意味着$C$为下三角阵。

思考题2：证明可逆下三角方阵的逆为下三角阵。

令$A$为$n$阶可逆下三角方阵，且$B$为$A$的逆。$A$可逆意味着$a_{i,i} \neq 0$，$i = 1, \cdots, n$。由$AB = I$，我们有

$$
\sum_{k=1}^{n} a_{i,k}b_{k,j} = \delta_{i,j}
$$

其中若$i = j$则$\delta_{i,j} = 1$，否则为零。对于上述等式，令$i = 1$，则有$a_{1,1}b_{1,j} = \delta_{1,j}$。因为$a_{1,1} \neq 0$，且$\delta_{1,j} = 0$对于$j > 1$，所以$b_{1,j} = 0$，$j > 1$。

然后令$i = 2$，则有$a_{2,1}b_{1,j} + a_{2,2}b_{2,j} = \delta_{2,j}$。令$j > 2$，则$b_{1,j} = \delta_{2,j} = 0$。再考虑到$a_{2,2} \neq 0$，我们有$b_{2,j} = 0$，$j > 2$。

将此过程继续下去，可得$b_{i,j} = 0$，$i < j$。所以$B$为下三角。

思考题3：证明向量空间中的$Cauchy$-$Schwarz$不等式，即

$$
|\langle a, b \rangle| \le \|a\|_2 \|b\|_2
$$

令

$$
A = \sum_{i=1}^{n} a_i b_i, \quad B = \sum_{i=1}^{n} a_i^2, \quad C = \sum_{i=1}^{n} b_i^2
$$

再定义$f(x) = Bx^2 + 2Ax + C$。经过直接计算，有

$$
f(x) = \sum_{i=1}^{n} (a_i^2 x^2 + 2a_i b_i x + b_i^2) = \sum_{i=1}^{n} (a_i x + b_i)^2 \ge 0
$$

因此$f$的判别式应小于等于零，即$A^2 \le BC$。所以不等式成立。

此外，可以看出当$a, b$线性相关时，$f$存在一个零点。此时判别式应为零。因此$Cauchy$-$Schwarz$不等式中等号成立当且仅当$a, b$线性相关。
